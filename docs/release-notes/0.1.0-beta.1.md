The first beta of Freeloop: a macOS app that runs coding agents, its own and Claude Code, Codex CLI, Gemini CLI and OpenCode, under your permission policy and with one bill across all of them. It is shared privately with a few testers; please report what breaks.

**Before you install.** The app is not signed or notarized (see OQ-009 in `docs/OPEN_QUESTIONS.md`). Check the download first:

```sh
shasum -a 256 -c SHA256SUMS --ignore-missing
```

Open the DMG and drag Freeloop to Applications. macOS blocks it the first time: try to open it, then choose **Open Anyway** in System Settings, under Privacy & Security. The Keychain asks again after each update, because the signature changes with every build. Needs a Mac with Apple Silicon (M1 or later) and macOS 14 or later; there is no Intel build.

**What is in this release.** `Freeloop.dmg`; `SHA256SUMS`; `APP-FILES.sha256` with every file in the app; `Freeloop.sbom.cdx.json`, the bill of materials; `THIRD_PARTY_NOTICES.txt`; and `BUILDINFO.txt`, the tools it was built with, so you can rebuild it and compare (`docs/DEVELOPING.md`, "Making a release").

**Known gaps in this beta.**
- The update check works only once the repository is public, and never offers a pre-release.
- Gemini CLI reports no model, so its usage has no price; OpenCode reports no tokens, which the app says rather than showing $0.
- goose's version is not pinned yet, so its checks are skipped.
- What each requirement was checked with, and what still waits for real use, is in `docs/CHECKLIST-0.1.md`.
