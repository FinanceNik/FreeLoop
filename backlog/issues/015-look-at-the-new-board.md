## What
A person uses the new Board on real projects for a day and says what still reads badly.

## Acceptance
- Checked in light and dark, at the window's smallest width and with the text size raised.
- An AFK run on a real project goes through the board from Backlog to Done, with one request answered on its card.
- Nothing overflows, and what waits for the user is the first thing the eye finds.
- What is found is written as new issues or fixed.

## Notes
- The tests cannot tell whether the board is pleasant to read; this is that check.
