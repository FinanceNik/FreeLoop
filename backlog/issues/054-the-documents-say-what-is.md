## What
What a stranger reads first is out of date. VISION.md says "a macOS app", "No Windows or Linux builds for now" and "No accounts, no sync, no server component", while the app builds for three systems and answers paired phones. ARCHITECTURE.md (line 382) says a virtualized list and 30 ms coalescing. The JSON-RPC socket is called the same API with another transport and has 17 of the service's methods. The corrections of fact are made, and the product is said to be what OQ-054 settled on 2026-11-11: the host first, "your policy and your bill over every agent you run", with the built-in harness as the agent that needs no vendor.

## Acceptance
- VISION.md, README.md, ARCHITECTURE.md and CLAUDE.md agree with each other and with the code on: the systems supported and what has been run on each; the phone server; how the conversation is drawn; what the socket offers.
- Every "not yet run" stays said, in the README too: a reader learns from it that Windows has not been run on Windows until 055 is done.
- VISION.md's comparison names the open-source ACP desktop clients found on 2026-11-11 (Acepe, ACP UI, OneAgent, Harnss, Agentaps, Crafter Code) once each has been read at its source, and says what was and was not checked.
- "Where Freeloop is genuinely different" claims nothing issues 033 to 039 have not made true.
- VISION.md's opening, "What Freeloop is" and "Where Freeloop is genuinely different", the README's first screen and CLAUDE.md's "What this is" lead with the policy and the bill over every agent; the built-in harness is described as the agent that needs no vendor, and nothing says it is frozen or lesser. The user reads the new wording before it is committed.
